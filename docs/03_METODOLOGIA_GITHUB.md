# Método de esta sesión: commits directos a main

El equipo usará [TAREAS_EQUIPO.md](../TAREAS_EQUIPO.md) como guía de trabajo.
Este acuerdo sustituye el flujo de ramas por tarea y pull requests propuesto inicialmente.

- Un clon independiente por colaborador, todos en main.
- Un responsable por componente y archivos definidos.
- El integrador sube modelo e interfaces antes del trabajo paralelo.
- Cada colaborador valida, hace commit de sus archivos, ejecuta pull --rebase
  e integra lo que otros ya subieron antes de hacer push a main.
- No usar push --force ni compartir una carpeta entre agentes simultáneos.
- El integrador revisa los commits y prueba el conjunto antes de la demo.

El sprint dura 60 minutos: 5 de alcance, 7 de base común, 20 de desarrollo
paralelo, 10 de integración, 13 de Boomerang y 5 de cierre.

La revisión se hace sobre los commits subidos y mediante correcciones posteriores.
En esta sesión no se exige PR ni se crea una rama por tarea.
